# Deltaria Posters

Cafe & Bar Deltariaのワールドで表示するポスターです。

[ポスター一覧](https://taki98029.github.io/deltaria-posters/)

## 現在の2枚

1. Deltaria案内：`images/display/deltaria.png`（1448×2048、ワールド配信用）
2. 掲載ポスター募集：`images/posters/main/recruitment.png`（1024×1536）

既存ポスター原本は `images/posters/main/poster.png`（2481×3508）。募集ポスターの編集元は `poster-recruitment.html` です。募集窓口は「キャストまで」としています。

ワールドの受付ボードとメニュー6冊は6秒表示、Fade1.2秒、初期AUTO ON。PREV／AUTO／NEXTで本人の表示を切り替えます。

## 更新

現在は上記2つの固定URLを読みます。HTMLの変更だけではPNGは更新されないため、編集後に画像を書き出して同じ配信用ファイルへ反映してください。原本poster.pngも配信用コピーへの書き出しが必要です。GitHub Pages公開完了後、新たな読み込みで確認してください。

フォルダ内画像の自動列挙・GitHub Actionsによる変換は未導入です。旧slot0～2は互換用に残していますが、今回の2枚ループには含めません。
